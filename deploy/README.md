## First-time server setup

```bash
rsync -avz --exclude .venv --exclude .git --exclude __pycache__ \
  ./ do_redgreen:/opt/content-factory-bot/

ssh do_redgreen 'bash -s' < deploy/scripts/bootstrap.sh
```

Production `.env` lives only on the VPS (`chmod 600`). Generated by `deploy/scripts/write-env.sh`.

**Telegram bot token** (separate from Hermes — do not reuse `TELEGRAM_BOT_TOKEN`):

```bash
ssh do_redgreen 'printf "%s" "YOUR_BOTFATHER_TOKEN" > /root/.cfbot-bot-token && chmod 600 /root/.cfbot-bot-token'
ssh do_redgreen 'bash /opt/content-factory-bot/deploy/scripts/write-env.sh && systemctl restart content-factory-bot'
```

`content-factory-bot.service` starts only when `/root/.cfbot-bot-token` exists.
