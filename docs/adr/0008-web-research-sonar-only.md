# Web research via Perplexity Sonar on OpenRouter only (v1)

The **research step** uses `perplexity/sonar-pro` with fallback `perplexity/sonar` through OpenRouter—no separate Tavily/Serper integration in v1. A hybrid search API plus synthesizer would improve citation control but adds a second vendor and failure mode before the core Telegram loop is proven.

**Session default (grill Q8):** `web_research` is **on** at `/new`; Creators can disable it per session. **Cover generation** remains off by default.
