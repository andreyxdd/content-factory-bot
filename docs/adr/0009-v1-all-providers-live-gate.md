# v1 definition of done: all three providers publish in production

Shippable v1 means a Creator can connect **Telegram channel**, **Instagram**, and **LinkedIn** and successfully publish the same content session to each (with provider-specific formatting rules once defined). A Telegram-only or “IG beta” launch does not count as v1. Schedule and app-review risk are accepted; Meta and LinkedIn developer work must start in parallel with the bot core.
